## What You Will Learn

* What Git and GitHub are, and why every developer uses them
* Saving your work with commits, and reading your project's history
* Undoing mistakes safely
* Working on new ideas with branches, and fixing merge conflicts
* Putting your projects on GitHub, and working on them from two places
* Pull requests: how teams review and add each other's work

---

## Who This Course Is For

* Complete beginners who have never used Git
* Learners who know some programming (for example, the [JavaScript course](https://github.com/mohin-sheikh/javascript-basics-to-advanced)) and want to put their code on GitHub
* Developers who copy Git commands from the internet and want to understand them
* Anyone getting ready for a developer job, where Git is used every day

## How to Use This Course

**1. Go in order.** Every session builds on the ones before it.

**2. Type every command yourself.** Do not copy and paste. Typing is how you remember the commands.

**3. Run `git status` often.** It tells you what Git sees right now, and what to do next.

**4. Compare your output.** Your name, your dates and your commit IDs will be different. Everything else should match the session.

**5. Finish each session.** Read the beginner mistakes, do the practice exercises, and answer the interview questions.

Plan for **about 45 minutes per session**. At one session a day, you finish in about two weeks.

You can read every session right here on GitHub, or download the course

```bash
git clone https://github.com/mohin-sheikh/git-and-github-for-beginners.git
```
